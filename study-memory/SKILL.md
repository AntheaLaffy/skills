# 延续同一份学习记忆

先读取 `tomato-todo` 并调用应用 `get_memories`，需要当前学习位置时再读 `get_study_progress`。长期记忆仍保存在番茄 Todo；Codex 不为相同学情另建一份默认成绩册或记忆数据库，也不声称会自动记住未保存的对话。

## 记录什么

只保存有跨对话价值的长期愿景、当前阶段、明确时间限制、稳定偏好、已确认的薄弱点和复盘结论。一次任务失败不能推出人格或永久能力；不要保存完整聊天、冗长任务列表、完整答卷、账号密钥、令牌或密码。

用当前 `remember` schema 保存 `kind`、`text` 和 `source`。单条聚焦一个结论，写清来源日期、相关项目/任务/测评或文件位置，避免重复。

- 用户明确说过的事实：source 注明本轮明确说明及必要上下文。模型调用 `remember` 保存后仍为待确认，告知用户可在番茄 Todo 记忆面板确认，不伪造已确认状态。
- 模型推断：`kind=hypothesis`，注明统计窗口、证据和替代解释，不升级成事实。
- 阶段变化：`kind=progress`，注明日期与口径，下轮核对最新数据；长期记忆不替代正式逐条学情。
- 愿景、偏好或旧结论变化：当前明确说明优先；指出冲突，按实际可用接口处理，不默默覆写旧事实。当前工具未提供修改/删除或确认记忆时，请用户在应用面板处理，不直接编辑私有 state.json。

## 正式学情与记忆分开

实际学习位置、依据、状态和下一步通过 `education.recordProgress` 追加，保留 assistant 来源。用户在本轮明确确认的学习事实，可以再独立 `confirmProgress`；不确定内容仍待确认，不原地覆盖旧进度。此操作前读取当前教学契约，不能用记忆文本替代课程、提交、批改或复测记录。

“已确认”表示用户确认过，不表示永远正确。读取时检查日期、阶段和新证据，发现过期或矛盾就说明。应用断开时可整理待保存内容，明确尚未写回；只在工具成功后说已保存。
