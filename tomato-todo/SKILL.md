# 番茄 Todo 的 Codex 对话入口

Codex 承担对话、阅读资料、备课、命题与批改，番茄 Todo 保存任务、课程、正式测评、学情和记忆。两边使用同一个运行实例的数据；不要另建一套平行成绩册或假装聊天结果已经入库。

## 连接与数据入口

- 使用当前实际提供的 `tomato` MCP 工具。下文使用短名称，实际通常为 `mcp__tomato__get_context` 等；按当前工具清单解析，不能把应用的 `read_file`、`request_user_input` 与 Codex 自己的同名能力混用。
- 首次处理本轮学习事项先 `get_context`，按需再用 `get_tasks` 和 `get_study_progress(projectId, offset, limit)` 分页读取。空记录表示未知，摘要中的数量不能替代完整记录。
- 需要完整教学历史时 `export_backup`，再用应用 `read_file` 按 `/education` 中相关数组分段读取。不要为一个问题把整个备份灌入上下文。
- 应用必须运行。连接失败先核对实例和连接文件；不启动另一个数据库，不直接改 SQLite、私有 `state.json` 或授权文件。无法接通时可继续完成不依赖实时数据的草稿，明确哪些尚未写回。
- 若本机另有 `references/local-context.md`，只在查找资料、个人排期或排查连接时读取；该本机导航不随技能仓库发布。

## 按任务使用技能

| 工作 | 使用的技能 |
| --- | --- |
| 应试配置、学期、45 分钟课程、作业、批改、订正 | `exam-teaching` |
| 出题、组卷、复测、答案与评分标准、试卷审校 | 同时使用 `exam-authoring` |
| 根据课表与学情排任务、减量、挪动和拆分 | `study-planning` |
| 知识困难、投入变化、冲突和复盘 | `study-diagnosis` |
| 跨对话背景、偏好、来源与确认状态 | `study-memory` |

正式教学写入使用 `education`。操作前通过应用 `read_skill(name="exam-teaching", reference="contract.md")` 读取当前运行版本的字段；必要时读取对应随包技能。当前契约优先于本机缓存，不能猜字段。未连接时，可用 [教学字段快照](references/teaching-contract.md) 准备草稿，恢复连接后重读契约与数据再提交。

## 资料与教学产物

资料原文和备课产物保存在实际项目目录，应用资源登记保存相对路径。文件先落盘，再 `education.saveResource`；更新路径沿用资源 ID。Codex 能访问某个目录不表示番茄 Todo 已获授权，项目绑定与目录授权仍由用户在项目页设置。

资源登记、文件名、索引、课程到点结束、任务勾选和订正通过都不能单独证明已读或掌握。读取原文后才引用；掌握需要独立复测。正式教学记录、来源与确认状态保留在应用内。

## 调整任务与课表

单项使用当前工具清单中的建改任务、课表工具或 `dispatch`；正式教学使用 `education`，不能用普通 Action 或备份补丁伪造已发布题目与成绩。

批量调整按需读取应用 `read_skill(name="tomato-files")`，再读取其 `references/PLAN_FORMAT.md` 或 `references/BACKUP_FORMAT.md` 及必要 schema。只改普通安排优先计划 v6；它不承载正式学期、课程、作业或批改。完整备份 v4 含历史与状态，不能用它做普通排期来回覆盖。

导出最新文件 → 按稳定 ID 找到位置 → 带最新 `fileHash` 原子 `patch_file` → `review_file` → 在用户已授权的范围内 `apply_file`。每批补丁最多 200 项，先 `test` ID/旧值；数组增删后重读索引。来源或哈希冲突时重新导出并重放变更意图，不覆盖新进度，不伪造 `.origin`。大量计算可用应用 `stage_file` 挂接脚本产物的真实来源。

保留完成记录、实际用时、永久 ID 和原有引用；不重复安排已完成或作废实例，不把漏做自动变成次日欠账。保护中被拒绝时遵守软件约束，不解除保护或修改保护配置来应用学习计划。

## 报告结果

分别说明实际文件位置、成功写入的记录及未完成部分。只在工具返回成功后说已发布、已保存或已应用；重试前查已有 ID 与状态，避免重复发布。Codex 对话不接管应用的自动教学事件，不承诺关闭软件后执行或到点自动回复。
